## 服务器环境特殊处理（重打包时保留）
1. 出口代理需要认证，配置在 $GRADLE_USER_HOME/gradle.properties（systemProp.*）。
2. 出口有 TLS 拦截，CA（Hatch Sandbox Egress CA）已导入 JDK cacerts（alias hatch-egress-ca）。
3. 沙箱 IPv6 映射路由异常，所有 JVM 经 _JAVA_OPTIONS=-Djava.net.preferIPv4Stack=true 强制 IPv4；
   注意 Gradle 会过滤 org.gradle.jvmargs 里的自定义 -D，只保留 -Xmx/-Dfile.encoding，
   所以 IPv4 开关必须走 _JAVA_OPTIONS，不能只写 gradle.properties。
4. GitHub OAuth 凭据在 app/client.properties（权限 600），编译进 APK。
